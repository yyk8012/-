# Volume 1 — Valuation & Earnings

## 개요

Volume 1은 주식 밸류에이션의 기본 언어를 다룬다. 이 볼륨에서 다루는 지표는 모두 "이익"과 "자본"을 축으로 하며, PER·PBR·ROE가 서로 어떻게 연결되는지를 이해하는 것이 목적이다. 개별 지표를 각각 정의하는 것을 넘어, 한 지표의 변화가 다른 지표에 어떻게 파급되는지를 설명한다.

## 챕터 구성

### Chapter 1. EPS (Earnings Per Share)
- 지표 정의: Basic EPS, Diluted EPS, Reported vs Adjusted vs Normalized
- IAS 33 관점의 분자/분모 구성
- Earnings season과 EPS Surprise
- Quality of Earnings 판정
- Basic/Diluted 워크드 계산
- Forward EPS로 넘어가기 위한 발판

### Chapter 2. Forward EPS
- Trailing EPS vs Forward EPS
- 컨센서스 형성 구조 (IBES, FnGuide, Bloomberg)
- Bottom-up / Top-down 추정
- Estimate Revision Trend
- Earnings Bridge (매출 → EBIT → NI → EPS)

### Chapter 3. PER (Price-to-Earnings Ratio)
- Trailing PER, 계산과 함정
- 산업별 PER 밴드
- Justified PER (Gordon Growth 기반)
- Multiple Expansion / Contraction의 원인
- PER의 역수인 Earnings Yield와 채권금리의 관계

### Chapter 4. Forward PER & Target PER
- Forward PER 정의와 실무 사용
- Target PER 산정 방법론 (Historical, Peer, Justified)
- Target Price = Target PER × Forward EPS
- PER Band 차트 작성
- Sensitivity Table (Target PER × EPS 시나리오)

### Chapter 5. PBR (Price-to-Book Ratio)
- Book Value 정의와 IFRS상 자본 항목
- Tangible Book Value, ROE와의 관계
- 산업별 PBR 특성 (은행, 보험, 리츠, 제조업)
- Justified PBR = (ROE − g) / (COE − g)

### Chapter 6. ROE
- ROE 정의와 시점 이슈 (기초/기말/평균)
- Sustainable ROE
- Cost of Equity와 ROE Spread
- ROE 개선 경로 (마진/회전율/레버리지)

### Chapter 7. DuPont Analysis
- 3단계 DuPont (마진 × 회전율 × 레버리지)
- 5단계 DuPont (세율, 이자부담 반영)
- Peer 비교 프레임
- DuPont을 통한 실적 서프라이즈 진단

## 학습 순서 권장

Ch.1 EPS → Ch.2 Forward EPS → Ch.6 ROE → Ch.7 DuPont → Ch.3 PER → Ch.4 Forward/Target PER → Ch.5 PBR

이유: EPS와 ROE가 나머지 지표의 재료이므로 먼저 정의를 확정한 뒤, DuPont으로 ROE를 분해하고, 그 위에 PER/PBR을 얹는다.
