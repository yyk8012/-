# Session03 — 시장 구조 (Market Structure)

## 개요

Session01~02는 "이 회사는 얼마의 가치가 있는가"(밸류에이션)를 다뤘다. 그러나 주가는 가치만으로 움직이지 않는다. **누가, 왜, 어떤 제약 하에 사고파는가** — 즉 수급(需給)이 단기·중기 주가를 좌우한다. Session03은 이 축을 다룬다.

핵심 전환: 밸류에이션이 "가치(value)"의 언어라면, 시장 구조는 "흐름(flow)"의 언어다. 패시브 자금의 기계적 매매, 지수 편입·편출, 외국인 자금의 유출입, 프로그램 차익거래, 공매도와 대차 — 이들은 밸류에이션과 무관하게 주가를 만든다. 기관 애널리스트는 "가치"와 "흐름"을 함께 읽는다.

## 콘텐츠 구성 (파일)

### 01. ETF와 패시브 투자의 구조
- ETF의 설정·환매(Creation/Redemption) 메커니즘, AP·LP
- NAV·괴리율(Premium/Discount), 추적오차(Tracking Error)
- 패시브 자금 성장이 시장에 미치는 구조적 영향
- 인덱스 편입·편출 효과, 리밸런싱 수급

### 02. 패시브 vs 액티브
- 벤치마크, 알파·베타, 정보비율(IR)
- Grossman-Stiglitz 역설과 시장 효율성
- 액티브 운용의 구조(집중도, 액티브셰어, 추적오차 예산)
- 패시브화가 가격발견·상관관계에 미치는 영향

### 03. 외국인 투자자와 글로벌 자금
- MSCI·FTSE 지수 체계와 편입·비중
- 외국인 수급의 성격(패시브 vs 액티브, 캐리 vs 롱텀)
- 환율·환헤지와 외국인 자금
- 신흥국 자금 흐름(Risk-on/off)과 한국 시장

### 04. 수급 분석 (투자주체·프로그램·공매도)
- 투자주체별 매매(외국인·기관·개인·연기금)
- 프로그램매매·차익거래(Basis)와 선물·현물 연계
- 공매도·대차거래, 숏커버링
- 수급 지표의 해석과 밸류에이션과의 결합

## 학습 순서 권장

01 ETF/패시브 → 02 패시브 vs 액티브 → 03 외국인 → 04 수급 분석

이유: 패시브의 구조를 먼저 이해하고, 액티브와의 대비로 시장 효율성을 본 뒤, 한국 시장의 최대 변수인 외국인 자금을 다루고, 마지막에 투자주체·프로그램·공매도의 실전 수급으로 종합한다.

## Session01~02와의 연결

- 밸류에이션(Session01~02)이 **중장기 주가의 앵커**라면, 수급(Session03)은 **단기·중기 주가의 힘**이다.
- 인덱스 편입 효과, 외국인 자금 유입은 밸류에이션과 무관한 수급 요인이지만, 종종 밸류에이션 갭 해소의 **촉매**가 된다(Session02의 04 촉매 논의).
- 공매도·대차 데이터는 시장의 반대 뷰(Variant Perception, Session01의 02)를 읽는 창이다.
