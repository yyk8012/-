# Session02 — 밸류에이션 심화

## 개요

Session01이 이익·자본·수익성의 배수(EPS·PER·PBR·ROE·DuPont)를 다뤘다면, Session02는 그 배수를 넘어 **성장·자본구조·현금흐름·목표주가**로 밸류에이션을 확장한다. 핵심 질문은 하나다. "PER 하나로 담기지 않는 것들 — 성장의 속도, 부채의 무게, 미래 현금흐름의 현재가치 — 을 어떻게 값으로 옮기는가."

Session01의 배수는 '상대 밸류에이션'이었다. Session02는 상대 밸류에이션을 정교화(PEG, EV/EBITDA)하고, 나아가 **절대 밸류에이션(DCF)**으로 넘어간 뒤, 이 모두를 하나의 **목표주가(Target Price)**로 종합한다.

## 콘텐츠 구성 (파일)

### 01. PEG (Price/Earnings-to-Growth)
- PER의 성장 조정: PER ÷ 이익성장률
- PEG의 기준점(1)과 함정
- 성장의 질·지속성과 PEG
- PEG vs Justified PER의 관계
- 고성장주 밸류에이션에서의 사용과 한계

### 02. EV/EBITDA
- Enterprise Value(EV) 정의와 자본구조 중립성
- EBITDA의 의미와 한계(감가상각·자본지출 무시)
- EV/EBITDA vs PER: 언제 무엇을 쓰는가
- 산업별 EV/EBITDA 밴드, M&A·LBO에서의 사용
- EV/EBIT, EV/Sales, EV/FCF로의 확장

### 03. DCF (Discounted Cash Flow)
- 절대 밸류에이션의 논리: 미래 FCF의 현재가치
- FCFF vs FCFE, 할인율(WACC vs COE)
- 예측기간·터미널 밸류(영구성장 vs Exit Multiple)
- 민감도·시나리오, DCF의 강점과 취약성
- Reverse DCF: 주가가 함의하는 성장 역산

### 04. Target Price 종합
- 상대·절대 밸류에이션의 삼각측량
- 방법별 가중과 블렌딩
- Sum-of-the-Parts(SOTP), 지주회사 할인
- 목표주가 → 투자의견, 사후 트래킹
- 밸류에이션 리포트의 완성 구조

## 학습 순서 권장

01 PEG → 02 EV/EBITDA → 03 DCF → 04 Target Price 종합

이유: 상대 밸류에이션의 정교화(PEG·EV/EBITDA)를 먼저 익힌 뒤, 절대 밸류에이션(DCF)으로 깊이를 더하고, 마지막에 모두를 목표주가로 종합한다.

## Session01과의 연결

- **PEG**는 Session01의 03(PER)·02(Forward EPS 성장)의 확장이다.
- **EV/EBITDA**는 Session01의 03에서 지적한 PER의 자본구조 한계를 보완한다.
- **DCF**는 Session01의 06(ROE·자본비용)·07(DuPont 드라이버)을 현금흐름·할인율로 재구성한다.
- **Target Price 종합**은 Session01의 04(Target PER × Forward EPS)를 다방법 블렌딩으로 확장한다.
